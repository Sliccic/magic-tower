# 🏰 经典魔塔三部曲合集 · 网页重制版 (自带内置作弊器/修改器)

这是一个用纯原生网页技术制作的经典魔塔合集游戏，包含了大家童年最熟悉的**三大经典正统魔塔版本**。无需安装任何额外插件或软件，解压或下载后双击即可在电脑浏览器中直接游玩！

---

## 📖 项目简介

本游戏将童年时期的三大经典魔塔完整搬到了现代网页浏览器中：
* **完全离线单机运行**：不需要联网、不需要配置复杂的开发环境，开箱即玩。
* **原汁原味还原**：保留了原版的像素画面风格、经典音效与战斗数值公式。
* **自带全能修改器（GM后台）**：卡关时随时按快捷键唤出修改器，支持一键无敌、随意穿墙、增加钥匙/血量/攻防、全图秒怪、自由传送楼层。

---

## 🎮 包含的三大经典版本

进入游戏首页后，可自由选择游玩以下三个版本：

### 1. 经典 21层 / 24层魔塔（胖老鼠版）
* **特色**：国内最广为人知的魔塔版本。
* **关卡**：包含第 0 层牢房救小偷剧情、1 到 20 层主塔、21 层决战魔王救公主，以及 22 到 24 层的隐藏神秘地下龙渊（挑战远古魔龙）。
* **机制**：神圣十字架攻防加成、幸运金币双倍掉落、中心对称飞行器、破冰镐破冰等经典道具全部还原。

### 2. 经典 50层魔塔（渡部直 1996年原版）
* **特色**：魔塔游戏的鼻祖，由日本作者渡部直制作的原版 50 层魔塔。
* **关卡**：严谨还原全套 50 层关卡地图，步步为营的经典数值解谜。
* **机制**：包含倍率递增的金币/经验圣坛、红黄蓝大门精密算式、隐藏密道与最终魔王决战。

### 3. 新新魔塔（56层革新版）
* **特色**：玩法策略最丰富、系统最庞大的革新之作。
* **关卡**：共有 **56 层立体迷宫**（主塔 21 层、地下侧塔 25 层、秘密魔塔 10 层）。
* **全新系统**：
  * **暴击与闪避**：战斗中不仅看攻防，还会触发暴击与身手闪避，并在画面中实时显示跳字。
  * **转职系统**：勇者之证、霸者之证、贤者之证三大职业进阶。
  * **特殊机制**：绿钥匙与结界绿门、十字架在濒死致命伤害时自动触发“神迹复活”恢复 2000 点生命、屠龙匕首恶龙伤害翻倍、解毒药水与解衰弱药水。

## 🚀 如何开始游玩

你可以通过以下任意方式在本地启动游戏：

1. **方法一：一键启动（最推荐）**
   * 双击文件夹中的 **`start.bat`** 文件。
   * 电脑会自动启动本地轻量服务并在默认浏览器中打开游戏页面。

2. **方法二：直接用浏览器打开**
   * 直接用鼠标把 **`index.html`** 文件拖拽到 Edge、Chrome 等任意浏览器窗口中即可直接开始。

3. **方法三：命令行启动**
   ```bash
   node server.js
   ```
   然后在浏览器打开 `http://localhost:8080`。

## ⚡ 内置作弊器（GM 修改后台）使用指南

游戏中随时可以开启修改器，帮助你轻松通关或研究路线。

* **如何打开修改器**：按键盘左上角的 **`~`（波浪号键）**、**`F1` 键**，或者直接点击游戏画面右上角的 **`⚡ GM 控制后台`** 按钮。

### 修改器支持的功能：
1. **人物数值修改**：
   * 生命值、攻击力、防御力随意修改，支持一键补满血、一键锁血、增加神力。
   * 金币、经验值、等级任意调控。
2. **钥匙与背包修改**：
   * 黄钥匙、蓝钥匙、红钥匙随时增加 10 把或直接调成 99 把。
   * 一键获得全套神装（神圣之剑、神圣之盾、怪物洞悉手册、神圣十字架等）。
   * **全图吸取**：一键把当前楼层的所有钥匙、宝石和血瓶全部吸入背包，免去跑图收集！
3. **特权超能力开关**：
   * 👻 **幽灵穿墙**：无视所有墙壁和大门封锁，全图随意穿行。
   * 🛡️ **绝对无敌**：受到任何怪物的攻击伤害恒定为 0。
   * ⚔️ **一击必杀**：任何小怪或终极首领，一刀直接斩杀。
   * 🗝️ **万能钥匙**：开任何门零消耗，不需要对应钥匙。
   * 👁️ **全图显伤**：所有怪物体力栏上方实时标注预计扣血数值。
   * 🧹 **一键清怪**：瞬间秒杀当前楼层所有怪物并全额结算金币与经验。
4. **楼层任意传送**：
   * 可以直接瞬间跳转到该版本的任意楼层（包括新新魔塔全部 56 层），无需反复爬楼。
5. **存档与读档**：
   * 支持快速存档与读档，即使关闭浏览器重新打开也可以继续上次进度。

## ⌨️ 游戏常用快捷键

| 按键 | 功能说明 |
| :--- | :--- |
| **W / A / S / D** 或 **方向键 ↑ / ↓ / ← / →** | 勇士移动 |
| **~** 或 **F1** | 打开 / 关闭内置作弊修改器 |
| **L** | 打开怪物洞悉手册（查看怪物属性与预估伤害） |
| **J** | 使用楼层传送圣器（跳转已到达过的楼层） |
| **C** | 使用中心对称飞行器 |
| **F5** | 快速保存进度 |
| **F9** | 快速读取进度 |
| **空格键 (Space)** 或 **回车 (Enter)** 或 **Esc** | 关闭对话弹窗或退出菜单 |
