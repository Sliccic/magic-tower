本游戏使用纯原生 **HTML5 + Canvas + Web Audio API + ES6** 构建，**零第三方 npm 依赖，零外部图片/音频文件加载限制**，纯静态本地运行，可在 Windows 及任意设备浏览器中即开即玩！

## 🎮 三大正统版本全部实装

首页提供三大经典版本选择入口，独立数据流与纯正原版体验：

1. **经典 21层 / 24层魔塔（胖老鼠版）**：
   * 包含 0F 牢房序章、1F~20F 经典爬塔关卡、决战 20F 冥灵魔王、21F 拯救公主。
   * 包含 22F~24F 隐藏地下龙渊与终极远古魔龙 Boss 战。
   * 支持神圣十字架攻防加成、幸运金币双倍掉落、破冰镐破冰、中心对称飞行器等经典机制。

2. **经典 50层魔塔（TSW 渡部直 1996 鼻祖版）**：
   * 严谨还原 1996 年日本 TSW 原版 50 层全部官方关卡地图数据。
   * 包含倍率递增金币/经验圣坛、红黄蓝大门精密算式、隐藏密道与魔王决战。
   * 纯正原版像素精灵图（Enemy1~15、Item1~3、Store、Door、Gem 等）。

3. **新新魔塔（56层策略革新版 - cos105hk）**：
   * 包含 **主塔 0F~20F**、**地下侧塔 B1F~B25F**、**秘密魔塔 M1F~M10F** 全部 56 层官方完整立体迷宫地图。
   * 全面实现 **暴击率 (`cri`)** 与 **敏捷闪避 (`agi`)** 数值系统，HUD 动态显伤。
   * 引入 **勇者之证**、**霸者之证**、**贤者之证** 三大转职之证及对应战力进阶。
   * 包含绿钥匙与结界绿门、十字架致命濒死触发 **+2000 HP 神迹复活**、屠龙匕首恶龙伤害翻倍、解毒/解衰药水等核心机制。
   * 完整支持 62 种新新怪物与 244 种独立图块精灵映射。

## ⚡ GM 控制后台与超能力功能

按键盘 **`~`（波浪号键）**、**`F1`** 或点击游戏右上角的 **`⚡ GM 控制后台`** 按钮即可呼出侧边调控抽屉：

### 1. 人物数值调控
* **生命值 (HP)**：实时输入或一键 `+1000`、`999999 (锁满血)`。
* **攻击力 (ATK)**：实时输入或一键 `+50`、`9999 (神力)`。
* **防御力 (DEF)**：实时输入或一键 `+50`、`9999 (铜墙铁壁)`。
* **金币 / 经验 / 等级**：随意调整。

### 2. 道具与背包修改
* **钥匙增减**：黄钥匙、蓝钥匙、红钥匙支持自定义输入或一键 `+10` / `99把`。
* **一键神装**：瞬间灌注圣剑、圣盾、十字架神物、怪物手册。
* **全图拾取**：一键将当前楼层的所有钥匙、宝石、药水全数吸取！

### 3. 特权超能力开关
* 👻 **幽灵穿墙 (Noclip)**：无视所有墙壁、封印与大门，全图自由漫游！
* 🛡️ **绝对无敌 (God Mode)**：受到怪物的反击伤害恒定为 0。
* ⚔️ **一击必杀 (One-Hit KO)**：任何小怪与大 Boss 一回合斩杀！
* 🗝️ **万能钥匙 (Master Key)**：开任何门零损耗，无视钥匙要求。
* 👁️ **全图显伤 (Always Show Damage)**：怪物头顶实时标注预测扣血数值。
* 🧹 **一键清怪**：瞬间秒杀当前层所有怪物并结算全额金币与经验。

### 4. 空间跃迁与预设
* **楼层任意传送**：支持全部版本所有关卡瞬间直达楼梯口（涵盖新新魔塔 56 层全部楼层）。
* **一拳超人模式预设**：满血满攻防全特权秒杀模式。
* **本地存档 / 读档**：支持 LocalStorage 快速存档读档，以及 JSON 导入导出。
